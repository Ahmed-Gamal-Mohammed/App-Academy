You will learn how to level up your skill to start implementing more powerful processes  
- Writing clean, readable, maintainable code 
- Understanding and implementing the basic of Object-Oriented Programming 
- Testing and validation that your code works now and in the future 
- Constructing efficient, Scalable, data structure and algorithms 
- Packaging and exporting your code for other developers to use 
- Importing code from other developers for use in your projects 

The keys to success in this module are pair programming, problem solving, and communication.

As you progress through App Academy, the problems will get bigger and more difficult. At times, you may find yourself so lost and confused that you struggle to even come up with a question. Whenever you are stuck, remember Polya's problem solving framework:
1. Understand the problem
2. Come up with a plan
3. Execute the plan
4. Revisit and refactor your solution

If you are stuck on execution, revisit the plan.

If you can't come up with a plan, make sure you understand the problem.

If you don't understand the problem, or you do understand but can't come up with a plan, spend time with your programming partner to come up with a _great_ coding question. Great questions are:
1. Specific
2. Clear and concise
3. Show you put work into it

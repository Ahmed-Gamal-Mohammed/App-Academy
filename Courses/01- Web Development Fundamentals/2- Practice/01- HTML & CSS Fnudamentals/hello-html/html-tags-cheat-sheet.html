Headings

Headings from `h1` to `h6` identify blocks and sections. Every page must have one `h1`.

Paragraphes

Paragraphes of text go in `p` tags.

Lists

Unordered Lists

Unordered lists are marked with bullet points and go in `ul` tags. Each list item goes in an `li` tag.

Types of lists

  • Unordered lists (`ul`)
  • Ordered lists (`ol`)

Lists

Ordered Lists

Ordered lists are numbered and go in `ol` tags. Each list item goes in an `li` tag.

Anchors (i.e links)

Anchors tags create links to other pages. The URL goes in the `href` attribute. it's will be opened in the same page Go to DuckDuchGo to search for more information

Setting `target = "_bland"` will open the link in the new window. See MDN for more details

Anchor tags can also create links to a new location on the same page, Instead of putting URL goes in the "href" attribute, jsut use the "id" of the element you want to navigate to, This allows you to jump to the top of the page

Text Emphasis

Italic

The `em` element adds extra emphasis to the text within the opening and closen tags. This shows up as italic text in most browsers

Bold

You can also use the `strong` elment to emphasize text. This shows up as bold text in most browsers.

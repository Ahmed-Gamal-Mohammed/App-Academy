# Server-side vs. client-side applications
In web development, a **server** is a computer or system that provides functionality to web browsers (or mobile applications) by communicating over the Internet. The browser or mobile application is commonly called the **client**. Both the client and the server run applications that developers create.

A **client-side application** runs on a user's laptop, phone, tablet or other device. One example of a client-side application is a website built with HTML, CSS, and JavaScript.

A **server-side application** runs on a machine that is connected to the Internet, usually in a large facility of other similar systems. Many companies offer hosting services so businesses and developers can rent a small part of a server to host their server-side applications.


One example of a server-side application, is an Application Programming Interface (API), which allows other applications the ability to retrieve data from a database. Server-side applications can be written in JavaScript (for example, **Node.JS**), **Python**, **Ruby on Rails**, and many other languages.

# Using Postman
A great way to test an API you are building as a server-side application, or explore another API you need to connect to from a client-side application, is using the **Postman** desktop tool. Postman allows you to communicate with a server-side application by making requests, and viewing the responses.

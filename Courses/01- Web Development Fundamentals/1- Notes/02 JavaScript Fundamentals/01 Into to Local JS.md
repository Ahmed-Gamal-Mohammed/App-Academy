- **Substitution Strings**: These are placeholders within a string that will be replaced by actual values when the string is processed. In JavaScript, placeholders are often represented by `%s` for strings, `%d` for digits, etc.
		-`console.log("Hello %s, you have %d new messages", "Alice", 5, "Extra value");`
		- `%s` is a placeholder for the string `"Alice"`.
		- `%d` is a placeholder for the number `5`.

	In this case:
	- `"Hello %s, you have %d new messages"` becomes `"Hello Alice, you have 5 new          messages"`.
	- `"Extra value"` has no corresponding placeholder, so it is simply added to the end of the message.
	The output would be:
		`Hello Alice, you have 5 new messages Extra value`

## Measuring performance
The first step to improving efficiency is to measure it. You will start by measuring your code's speed through _timing benchmarks_, then learn to evaluate time and space efficiency just by reading the code through _big-O_ analysis.
## Choosing the right tool for the job
Once you can reliably measure code performance, the key to improving efficiency is choosing the right tool for the job. In most cases, that tool is either an _array_ or _hash table_.
## Problem solving
Every problem can be solved with Polya's problem solving framework. The projects over the coming days will take you on a deep dive of steps 1 and 4.
1. **Understand the problem**
2. **Come up with a plan
3. **Execute the plan**
4. **Iterate and improve your solution**

Understanding the requirements and constraints of a problem is the first step to solving it. Understanding how your data structures work underneath the hood will help you choose tools that make many problems easy.

Similarly, measuring performance and knowing how to improve it by efficient use of data structures will allow you to improve the performance of your code. It will also let you recognize when performance is a non-issue, allowing you to optimize for _readability_ instead.

Knowing how your code works will improve your decision-making process and make you a more confident programmer. Learning the vocabulary to describe code performance will make you a more effective communicator.

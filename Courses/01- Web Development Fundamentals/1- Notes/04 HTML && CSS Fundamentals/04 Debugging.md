2- CSS Tips and Tricks 
================================
1- Changing the background color 
	The first step of debugging is to try to find and isolate the problem. This can be done in various ways. Changing the background color of an element allows you to see what CSS is impacting which elements, allowing a more focused perspective to help you determine what needs to be changed or fixed.
2- Add a 10px solid red border
	Another way to try to isolate the problem is by putting a big red border around a specific element that you are working on. Just like a big red flag, it can pinpoint a feature that you want to change or come back to later. Putting a border around the element also lets you see the spacing around it which gives you a more accurate depiction of what it is affecting.
3- Linting 
	Linters are like the spell check of your coding environment. Everyone should have a linter installed that automatically checks your code for programmatic and stylistic errors. This is helpful in your everyday coding. It automatically analyzes your code and will highlight errors for you. Extremely useful to detect minor bugs while you code.
4- Browser Extensions 
	Lastly, browser extensions are helpful because they can be enabled and disabled at will. These are for more specific requirements when you are working on a certain library or framework. Simply put, they are extensions to your browser dev tools making them specialized towards what you are working on.
